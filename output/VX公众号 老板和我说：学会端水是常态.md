# 前言

>  周三早晨06:00突发问题开始修数据、抢救基线，直到14:00。像是我这周的缩影。

我一直觉得「数仓抢救基线 —— 生命线」这个说法莫名地好笑和无奈，像是给自己加了一出自我感动的戏码，但仔细想想又没觉得有什么问题。
但每个阶段都有每个阶段重要的事情，相比当下热火朝天的AI，团队似乎也不再投入过多精力在基线上，更多是保障不出错即可。
而公司的数据平台在本周初出现了故障，造成大面积数据任务的计算积压，这也导致了我本周在不同的地方救火。

# 01. leader找我 1:1 聊天，他说"端水是常态"

周三早晨09:00我就到了公司，因为06:00起床后我就再也没睡着，甚至人很疲惫但没有丝毫困意。我在楼下也遇到了早到的leader，他邀请我去抽根🚬，打量了下我的精神状态，顺便问了几句。我印象很深，那天早上我饭都还没吃，就感觉压力大到抽了3根。结束后我俩约了一个下午的 1:1 沟通。

在我2023年刚入职的时候，我被要求要积极支持好业务需求，不要有负向反馈。而这个要求我觉得和我的特性本身也比较契合：愿意积极满足他人的诉求，甚至是努力获取他人的好评。

但他周三给了我几个之前没听过的经验和感悟
1. 脱离纯一线执行后，不论是虚线小组长 POC 、还是真正的管理层。决策时只能满足部分需求是常态。
2. 要敢于做决策：一个决策可以放大 A 的收益，但同时也可能影响 B 的利益，这是比较常见的 —— 不要过度担心来自 B 的负向反馈（但我很好奇当 B 的负向反馈投诉到leader后，他是否就换一个口吻来和我沟通了哈哈）
3. 然后他说了那句正题："学会端水是一件必须要面对的事情"

听完后我的内心：你倒是早说啊。我觉得这话他不一定会和所有人说，因为我听了这段话后不会胡来，反而能减轻我的心理负担。或许这也算是管理的手段吧，就像佛陀对不同的弟子说不同的话。

# 02. 端水难，是因为我没有自己的原则

近段时间巴菲特所在的伯克希尔公司，持有的自由现金已超过资产的50%。
而瑞·达利欧的观点则更激进：他对以 AI 科技股为核心的美股上涨表达了"泡沫早期""债务风险加大"等强烈担忧。他也是一位超级大佬，5年前朋友送我的《原则》正是出自他的手笔，而我至今还未翻阅。其实之前一直以为是一本成功学介绍而嗤之以鼻。

我还是挺享受出差坐飞机的过程，因为这是难得与地面进行信号隔绝的时刻（我是死也不会买空中wifi的），而这正是阅读的最佳时机。本周二早晨的飞机，我就在阅读《原则》，截取几段分享给大家

> [!第一部分 4.我的试炼之路]
> 
> 想要改进你的决策，你能做的最有价值的事情之一，是深入思考你的决策原则，同时以文字和计算机算法的形式把这些原则写下来…假如没有这些系统，我很可能已经破产了，==或者因要从事如此繁重的工作而被压力逼死了。==
> 
> 大多数人都有情绪化倾向，不会严格遵守逻辑，所以他们通常会对短期结果反应过度…明智的人在经历各种沉浮时都始终盯紧稳健的基本面；而轻浮的人跟着感觉走，做出情绪化的反应。

这里达利欧讲的是投资交易系统，但"因要从事如此繁重的工作而被压力逼死了"对我这一周的状态过于精准。

并且回看我自己，业务同学来"哭诉"时，我大部分时候都会妥协，这就是典型的"对短期结果反应过度"。结果是我想做的事没按时完成，要靠额外时间回补，然后懊恼——这是一个循环。

*【图片位置 3 — unsplash 搜索关键词：reading on plane / book on tray table / window seat sunrise】*

我前段时间在《知行小酒馆》听到有知有行发起人之一「张潇雨」抛出一个词，命运杀猪盘 —— 命运会不断给你重复同一个问题，直到你给出不同的答案。对标到我的工作上，我忽然就想通了，源源不断的业务需求会一直提过来，直到我不再用"压榨自己"来即刻满足他们的诉求。

和老板聊完后，我觉得他说的"端水"、达利欧说的"原则系统"、张潇雨说的"给出不同答案"，似乎是一件事情的三种不同说法。

对我来说坏消息是我还不知道该如何解决现状；但好消息是我认识到了问题。期待我能像在公司内网写 blog 那样，慢慢地更新出一份属于自己的原则。

# 03. 公事公办，是我能用的最后一招

我们公司的数仓团队和业务团队其实是平行关系，更像是一个合作伙伴或乙方。数仓不承担业务结果，但业务给的反馈仍然会间接影响个人的心情和激励。

逃避和吐槽都不是解决问题的办法，单纯的公事公办也不一定能完全解决问题。所以我会尽力和业务团队私下多沟通，也让对方理解我们的难处。但这一招并不对所有人都有效，有些业务人员只管自己提需求，不管数仓和 DS "死活"，晚几天交付都不能接受，只有情绪但没有客观表达和沟通。面对这种情况我也只能公事公办，拉上各方一起讨论优先级。但我觉得很多时候，这就丧失了人与人之间的温度，可能也是我端水必须付出的代价之一。

# 尾声

周五下午需求评审之前，我特地整理了一下 UGC 方向的数仓需求积压情况，让在座的所有人感受一下当前的状态，努力拒绝了一些零散的诉求。这算是和老板那次 1:1 之后，我第一次像样的端水。

下周还有得忙，端水也还会继续。但至少现在我知道，这件事有它的名字了。
