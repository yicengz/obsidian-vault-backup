# 写作原则

用法：每写完一条词条，对照打勾；发现"这次哪里好/哪里不对"，就把经验沉淀成新的一行。

## 动笔前检查单

- [ ] 这条有具体的故事吗？（没有 → 降级为趣事）
- [ ] 故事里有时间、场景、人物吗？
- [ ] 联想超过两层了吗？（超了 → 多出来的存为种子）
- [ ] 每层联想之间有"跳板"吗？（跨两级读者就掉线）
- [ ] 最后一句回收了吗？
- [ ] 道理超过三句了吗？
- [ ] 化名和脱敏做了吗？
