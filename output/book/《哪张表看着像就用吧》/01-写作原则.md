# 写作原则

用法：每写完一条词条，对照打勾；发现"这次哪里好/哪里不对"，就把经验沉淀成新的一行。

## 动笔前检查单

- [ ] 这条有具体的故事吗？（没有 → 降级为趣事）
- [ ] 故事里有时间、场景、人物吗？
- [ ] 联想超过两层了吗？（超了 → 多出来的存为种子）
- [ ] 每层联想之间有"跳板"吗？（跨两级读者就掉线）
- [ ] 最后一句回收了吗？
- [ ] 道理超过三句了吗？
- [ ] 化名和脱敏做了吗？

## 增补区

<!-- 一行一条，随时增补 -->

- [ ] 从一件具体的小事起笔，撑竿跳跳到普遍，结尾一定回到那件小事（学老安，不落地成议论文）。
- [ ] 术语不解释、不道歉：先让同行会心一笑，再用生活场景让外行也懂情绪。
- [ ] 结尾不总结、不升华，留一句让人愣一下的话就停。
- [ ] 气呼呼可以，毒舌可以，底下要站着认真的人；自嘲时不能把事也写轻了。
