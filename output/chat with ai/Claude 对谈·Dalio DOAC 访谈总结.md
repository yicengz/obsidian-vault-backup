**源文档**：[[raw/clippings/Ray Dalio I Predicted The 2008 CRASH, I Know What Comes Next!|Ray Dalio: I Predicted The 2008 CRASH, I Know What Comes Next!]]（The Diary Of A CEO，发布于 2026-07-30，剪藏于 2026-09-04，见 [[20260904|当日日记]]）

## Dalio 的核心观点

### 1. 泡沫的机制：财富 ≠ 货币

- 反复强调的底层区分：**「你看到的是很多人变富有了，但财富不能花。你只能花钱，而花钱必须先卖掉财富。」**
- 例子：融资 $5000 万、估值 10 亿，纸面上你就是亿万富翁——但没人真的付过 10 亿。拿股票去银行抵押借 $50，一旦所有人同时要现金，股价跌到 $25，倒欠银行 $25，被迫抛售，螺旋开始。
- 20 年代的新技术（电、冰箱、汽车、飞机、收音机）**后来确实伟大，但「利润配不上价格」**——泡沫不是因为故事是假的。

### 2. 刺破泡沫的三根针

- **加息**（通胀期央行收紧，持债收益超过持股）
- **财富税**（迫使富人卖资产换现金）
- **股票供给激增**（「世界上没有比印股票更容易生产的东西」）

### 3. 泡沫不是是非题，是程度题

- 关键信号是**「弱手」入场**：不懂投资的散户加杠杆进来，或买杠杆 ETF，「更像在赌骰子」。

### 4. 资产配置观

- **现金是最差的长期投资**：通胀 3.5–4%，利息还要交税，长期必输。
- **分散化**不降低收益、只降低风险；股票熊市会跌 60–70%。
- **黄金**：1971 年之前它就是货币，至今是第二大储备资产，「唯一不是别人负债的金融资产」；硬资产建议配 **5–15%**。
- **比特币**自己只配 ~1%：同样是「印不出来的钱」，但可被监管、被量子计算威胁，央行永远不会大量持有（俄罗斯资产被没收了，黄金没有）。
- **房产**：强制储蓄 + 税收优惠 +「它是你的环境」。

### 5. 给普通人/年轻人的职业观

- **「历史上最成功的不是最聪明的人，是最能适应的人。」**（说了两次）
- 你唯一的资产是你自己；同一技能在不同行业定价天差地别（开 Uber vs 给 Ray Dalio 开车）；**「任何东西顶部 10% 都值平均值的很多倍——多好 10%，多赚一倍」**。
- 让孩子做热爱的事，但**「别忘了钱的部分」**；别押注某个具体职业（「以前说要学编程，然后 Claude Code 来了」），押注学习能力 + 了解自己天性。

### 6. AI 与就业

- 受益者是会用 AI 替代工人的「有想法的资本家」：企业营收中流向劳动者的份额在降、流向股东的份额在升。
- 身体被机器替代后人还能卖脑力；**「当脑力和身体都被替代了，你还剩什么可卖？」**——答案是情感和直觉，以及与 AI 协作的顶尖人类。
- 硅谷说「会像工业革命一样创造新岗位」，他提醒：**说这话的人正身处镀金时代，他们有立场**。

## Dalio 的预警

1. **AI 泡沫**：认同 Grantham——「从数据看，顶点很快到来与历史完全吻合，这可能是**美国历史上最大的投资泡沫**。」
2. **美英处在大周期后段（衰落期）**：过度负债 + 财富差距 + 政治极化 + 地缘冲突同时汇合。英国七年换六任首相就是症状——**「加税人就跑，减福利选民不答应，钱从哪来？」** 接下来很可能是债务重组 + 印钞 + 资本管制 + 离境税。
3. **伊朗战争是个大错误，且暴露了致命弱点**：直接类比**英国的苏伊士运河时刻**——「以前美国只要暗示一下，别国就会照做。现在灯泡亮了：**那个威胁不再有效了。**」推论：美国不会真正「出现在亚洲」；**「如果中国封锁台湾芯片出口 5 天，全球股市就会崩盘」**——这甚至不需要动武。
4. **财富税的现实困境**：就算把顶级富豪 100% 没收也不够填赤字；富人会跑，然后就是追溯性立法和资本管制——**「这些历史上全都发生过」**。
5. **内部撕裂大概率以冲突收场**：他举自己住的康涅狄格（人均收入全美第二的州）——**22% 高中生辍学或不及格，监禁开支超过了教育预算**。

## Dalio 提到的历史

| 历史参照 | 他用它说明什么 |
|---|---|
| **1929 泡沫 → 大萧条** | 新技术真实革命 + 借钱下注 + 忘记价格 = 繁荣如何产下萧条 |
| **2000 互联网泡沫** | 同一机制的又一次重演 |
| **1971 年金本位终结** | 黄金在此之前就是货币；它作为「非负债资产」的地位来源 |
| **工业革命 → 镀金时代 → 强盗大亨** | 「镀金时代看起来很像现在」——资本主义制造差距是周期的一部分 |
| **拖拉机替代耕牛 → 印刷术 → AI** | 机器先替代身体，现在向上替代思考与推理 |
| **1945 年** | 上一次 80 年大周期拐点：货币、国内政治、地缘三种秩序同时重建 |
| **过去 500 年多国周期** | 他强调用可测量的客观指标（负债、教育、竞争力），「像体检一样」 |
| **英国苏伊士运河危机** | 帝国霸权「露馅」的转折点，类比今天美国在伊朗/亚洲的处境 |
| **美国制宪会议** | 对立双方达成艰难方案的范例——他的药方是「强大中间派 + 两党委员会」 |
| **《孙子兵法》与朝贡体系** | 中国式力量运用：无法靠占领长期控制一个国家（伊朗有 9000 万人） |
| **桥水 2008** | 标普 -40% 时桥水 +9.5%；累计净收益 $530 亿、年化约 12%——预警的「资质证明」 |

## 结构性骨架

整场访谈的骨架是那张图：**技术线永远向上**（人不会忘记已学会的东西）× **6±3 年的小债务周期** × **约 80 年的大周期**（上次拐点 1945）。泡沫、衰退都是小周期的褶皱；现在特殊在于三条线正叠在同一个时刻。
