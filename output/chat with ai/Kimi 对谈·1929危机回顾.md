# Kimi 对谈·1929危机回顾

与 Kimi 就 [[《1929》]] 展开的完整问答。原始对话：

- 第一场：https://www.kimi.com/share/1a05e1a8-02a2-8d12-8000-0000823319cf
- 第二场（含 7 个追问）：https://www.kimi.com/share/1a06041d-ed12-86c2-8000-00000d30e2cf

## 背景

- 正在读 [[安德鲁·罗斯·索尔金]]《1929》（朱宁译），刚看完第一幕第一章《世间没有"信用魔法"结局不了的困局》。
- 因为最近工作太忙，内容有些忘了，让 Kimi 帮忙回忆米切尔和拉蒙特做了什么。
- 更关心的是：大萧条的根因、导火索、每个人的角色。

## 第一场：回顾第一章

- 第一章主角是拉蒙特，米切尔的重头戏在序幕和第三章。
- 拉蒙特赴欧谈德国战争赔款（后来的杨格计划）。
- 米切尔公开对抗美联储、3 月 26 日"叛乱"、用自家股票护盘。

## 第二场：7 个追问

1. 为什么一战前美国是债务国？→ 欧洲资本修铁路建厂；一战后翻转。
2. 投资信托叠杠杆的问题在哪？→ 杠杆数学、金字塔嵌套、不透明。
3. 明斯基三种融资 → 对冲 / 投机 / 庞氏。
4. 和中国房地产像不像？→ 住房贷款正常，但系统层面循环性、房企玩法像米切尔。
5. 1999 年拆墙怎么为 2008 开了门？→ 存款弹药、证券化流水线、大到不能倒。
6. 金本位为什么主动制造紧缩？→ 信心危机自动转化为货币紧缩。
7. 因果图 → Kimi 用 matplotlib 画了一张分层因果图。
