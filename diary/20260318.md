# P25
「**自我控制**」和「**认知努力**」是大脑工作的形式，这一观点已得到广泛认同。
过多关注自己完成一项任务的结果，就会给自己的短时记忆增加毫无疑义的思想负担，进而影响其整体表现。

可以掌控意志和进行自我控制，是很辛苦的。 —— 心理学家罗伊·鲍迈斯特的研究小组
如果你必须强迫自己去做某件事，而此时这件事又面临一个新的挑战，你就会很不情愿或是根本无法进行我我控制。这种线上被称为==自我损耗==。

| 书里的观点        | 我的比喻              |     |
| ------------ | ----------------- | --- |
| 强迫自己做某件事A    | 控制自己努力入睡          |     |
| 事A有面临一个新的挑战B | 但又想到明天的事情和万一告警怎么办 |     |

神经系统消耗的葡萄糖比身体其他部位消耗的都要多，而且需要付出脑力活动的成本显然要比葡萄糖高。在积极进行复杂的认知推理或者忙于要求自我控制的任务时，人的血糖就会下降。这种情况和短跑运动员在短跑是肌肉中的葡萄糖储备量下降是相通的。 —— 心理学家罗伊·鲍迈斯特的研究小组

貌似正确的答案会马上在大脑中显现。 P29
