# 债务-通缩

债务-通缩（Debt-Deflation）是欧文·费雪（Irving Fisher）对大萧条的解释：危机后货币供应萎缩、物价下跌，导致实际债务负担加重，债务人被迫削减支出，进一步压低物价，形成恶性循环。

## 机制

```plain
银行倒闭 → 货币供应萎缩 → 物价下跌 →
实际债务负担加重 → 债务人削减支出/抛售资产 →
物价进一步下跌 → 更多违约 → 更多银行倒闭
```

## 1929–1933 的数据

- 美联储在 1930–1933 年坐视近万家银行倒闭。
- 货币供应萎缩约三分之一。
- 弗里德曼和施瓦茨在《美国货币史》中把大萧条的主因归于美联储的货币收缩。

## 政策含义

- 危机中，央行应该充当「最后贷款人」，防止货币供应崩塌。
- 金本位下央行被黄金储备锁死，无法放水，反而被迫紧缩 → [[金本位]]。
