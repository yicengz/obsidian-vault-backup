# 泡沫往往始于真实的好故事

这句话总结了 [[《1929》]] 里 1920 年代美国的故事：分期付款买汽车、冰箱、收音机，投资信托把普通人带进股市——这些起初都是真实的技术与金融创新。问题不在「故事是假的」，而在于**好故事被加杠杆、被叙事化之后，价格远远脱离了价值**。

## 机制

1. **真实的好故事** → 汽车、收音机、分期付款、投资信托。
2. **信用扩张** → 「世界上没有信用魔法解决不了的问题」。
3. **杠杆叠加** → 10% 保证金、信托买信托、银行囤自家股票。
4. **叙事自我强化** → 「投资者买的不是公司，而是名声」。
5. **崩盘** → 当价格必须永远上涨才能维持债务时，庞氏结构当场窒息。

## 识别的线索

- 杠杆普及到普通人。
- 抵押物开始自我循环（银行囤自家股票、房企用预售款买地）。
- 央行政策被市场主体公开蔑视。
- 所有人都在说「这次不一样」「永久繁荣」。

## 与个人经历的连接

- 2021 年白酒基金：白酒是好行业，但「好行业 + 叙事 + 杠杆 + 全民参与」就是泡沫的配方。
