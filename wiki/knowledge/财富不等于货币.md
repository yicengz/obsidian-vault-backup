# 财富不等于货币

达利欧在 DOAC 播客里反复强调的一个区分：**你只能花钱，花不了财富（wealth is not the same as money）**。看到很多人「变富有」，但那只是资产标价上升；要真正使用，必须先卖出资产换成钱。这个看似 trivial 的区分，是理解泡沫如何形成、如何破裂的钥匙。

## 机制：上行放大，下行加速

1. 革命性技术出现（电、互联网、AI），人人想拥有它的一部分——[[泡沫往往始于真实的好故事]]。
2. 资产价格上涨 → 账面财富增加 → 可以拿财富做抵押去借钱 → 借来的钱再买资产 → 价格进一步上涨。抵押物顺周期自我强化。
3. 杠杆普及到「弱手」：无经验散户带着杠杆（如杠杆 ETF）入场，本质是在赌博——这是经典泡沫信号。
4. 某处出现**变现需求**：加息让债务偿付变贵、税负变化、或单纯有人需要现金 → 必须卖资产 → 价格下跌 → 抵押物缩水 → 被迫卖更多 → 支出收缩 → 他人收入下降 → 经济进入下行。链条与 [[债务-通缩]] 同构。

## 刺破泡沫的三根针（达利欧）

泡沫不是二元状态而是程度问题；刺破它的通常不是「利空消息」，而是**对现金的强制性需求**：

1. **货币收紧 / 加息**：持有债务的人需要更多钱付息，且更高利率让债券相对股票更有吸引力。
2. **税收**：如财富税，逼着富人卖资产缴税。
3. **股票供给激增**：「几乎没有比印股票更容易生产的东西」——当市场渴求股票时，IPO 和增发潮随之而来（2026 年：SpaceX 上市、Anthropic/OpenAI 筹备 IPO），供给放量本身压低价格。聪明的创始人会抢在泡沫破裂前融资。

## 投资含义

- 不要试图给泡沫择时——连成熟投资者也很难做到。
- 现金是最差的长期投资（通胀 3.5–4% 持续侵蚀，利息还要缴税），但**短期**国债等 fallback 现金垫是必要的安全边际。
- 分散化不降低长期收益，只降低风险：各资产由不同力量驱动（股、债、金、房、比特币），黄金在其他资产表现差时往往走强，达利欧建议 5–15% 配置硬通货，且在黄金与比特币之间首选黄金（政府干预风险、量子计算威胁）。
- 衡量自己的安全垫：如果收入归零，能撑多久？
