## 全文摘要

这期《知行小酒馆》,主播雨白对话石像科技的 AI 研究负责人凯西,聊 AI 变革的当下进展、大众体感的割裂,以及未来的方向。凯西先厘清 Agent 和传统聊天框 AI 的差别:传统 AI 只能单轮问答、整合内容,而 Coding Agent 已经能自主完成规划、检索、写码、实验复现的端到端工作流,覆盖绝大多数虚拟世界里的电脑操作,用户往往只需在初始规划阶段介入调整方向。他给出一组数据:Claude Code 是历史上增速最快的科技产品,用户量只有 ChatGPT 的 2% 却已登顶 AI 公司收入;原本一名员工要一周完成的调研,用 Agent 两小时就能交付;硅谷对冲基金一小时能做完纽约同行一周的活。有意思的是,零售、电商、中小微企业等非技术行业的渗透率反而更高。他也直言现有 Agent 产品设计反人性、还无法操作物理世界。谈到大众为什么体感割裂,他归因于技术迭代太快而扩散太慢——全球真正用过 AI 的人只占约 20%,加上试错成本顾虑和初期挫败感,很多人还没找到适配的用法;而 AI 落地进度更取决于你所在组织和圈子的包容度,与行业本身的技术属性关系不大。他认为大众普遍低估了知识工作的自动化程度,也提醒不必追逐标准答案:在 AI 时代,与其焦虑被替代,不如扔掉旧地图,主动去新世界里探索,绘制属于自己的人生路线。

## 问答回顾

**雨白 问:** Agent 和我们平时用的聊天框 AI 有什么本质区别?

**凯西 答:** 聊天框 AI 基本只能单轮问答、帮你整合内容;Agent 能自主完成规划、检索、写码、实验复现的端到端工作流,覆盖绝大多数虚拟世界里的电脑操作。你通常只需要在它输出初始规划时介入调一下方向,后面基本不用盯着。

**雨白 问:** 有没有具体数据能说明 AI 现在有多能干?

**凯西 答:** Claude Code 是人类历史上增速最快的科技产品,用户量只有 ChatGPT 的 2%,收入却已登顶 AI 公司。投研、AI 研究这类调研任务,员工原本要一周,用 Agent 两小时左右就能交付核心成果;硅谷对冲基金用 AI 一小时,能做完纽约同行一周的调研。

**雨白 问:** 为什么大家对 AI 的体感差别这么大?

**凯西 答:** 核心是技术迭代太快、向普通用户的扩散太慢。全球真正用过任意一款 AI 产品的人只有约 20%,能把它当核心生产力工具的更少。很多人担心调试的时间成本比自己干还高、初次使用又容易挫败,所以迟迟没上手。落地进度更取决于你所在组织和圈子的包容度,而不是行业本身技术不技术。

**雨白 问:** 现在的 Agent 还有什么明显做不到的?

**凯西 答:** 一是产品设计还很反人性,没把需求拆解、任务规划、进度监督这些能力内置进去,门槛偏高;二是它还处理不了物理世界的实体操作,一些复杂场景的事实核查也仍然需要人来把关。

**雨白 问:** 普通人面对 AI 时代,应该抱什么心态?

**雨白 答:** 不必追逐标准答案,也不用被替代焦虑绑架。像本期主题说的——扔掉旧地图,主动到 AI 时代的新世界里尽情探索,绘制属于自己的人生路线,比原地担心更有用。
