# 不要拿着锤子找钉子

## 一、我找到了哪几颗钉子

AI 热潮里有一种普遍焦虑——感觉自己没在用 AI 就落后了。今天不讲 AI 有多厉害，只讲我自己真正用起来的几件事。

---

## 二、钉子一：知识库

**痛点：** 信息很多，留不住。看了就忘，感觉在原地踏步。

**工具组合：Obsidian + Web Clipper + Claude Code**

- **Obsidian Web Clipper** — 浏览器插件，看到好文章一键剪藏，自动带标题、链接、日期
- **Obsidian** — 本地笔记软件，raw/ 存原材料，wiki/ 存 AI 整理后的知识页
- **Claude Code** — 把新素材丢进来，AI 读、提炼、写入 wiki，和已有内容建立关联

[核心思路来自 Andrej Karpathy：**知识只编译一次，但一直在复利。**](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)

> 📌 演示：Web Clipper 剪藏 → Obsidian 结构 → Claude Code 整理写入 → 展示成型的 wiki 页面

---

## 三、钉子二：个人网站

**痛点：** 想有一个对外展示自己的地方，但不会写代码。

**做法：** 用 Claude Code 写网站。我是产品经理，它是工程师。

这还是个半成品——但它真实存在。一个不会写代码的人，用 AI 做到了这件事。

关键：**你得知道自己想要什么，AI 才能帮你做出来。**

> 📌 演示：打开个人网站，展示现有页面 http://localhost:3000

## 四、给金融从业者的推荐：Perplexity

AI + 搜索的结合。每个回答都附带原始资讯链接，可以溯源。

适合用来：快速了解行业动态、政策变化、公司背景。比直接问 ChatGPT 更可信，因为你能看到它从哪里来的。

把它当**有判断力的搜索引擎**，不是用来做决策，而是用来快速建立背景认知。

> 📌 演示：现场搜一个金融相关问题，展示返回结果和来源链接 http://localhost:3001

## 五、收尾

回到开头：你找到你的钉子了吗？

我的判断标准：
1. 这件事有没有明确的痛点？
2. AI 做完之后，判断权还在不在我手上？

**AI 是工具，不是方向。方向还是得自己找。**
