# Claude Code

## V1

### 开场：大家都在拿着锤子找钉子（5分钟）

AI 热潮里有一种普遍焦虑——感觉自己没在用 AI 就落后了，所以开始把所有事情都往 AI 上套。结果要么用得很勉强，要么用了之后觉得"也不过如此"。

这种状态叫"拿着锤子找钉子"。锤子没问题，但不是所有东西都是钉子。

**我今天想分享的，是我找到的两颗真正的钉子。**

---

### 案例一：我的知识库（15分钟）

**问题是什么：**
我平时看很多东西——文章、书、播客、视频——但信息是散的，过一段时间就忘了，感觉在原地踏步。

**普通人的解法是 RAG：**
就是把文章都上传到一个 AI 工具，然后问它"帮我找找关于投资的内容"。这种方式每次都从零开始，没有积累。

**我在用的方式：**
我用一个叫 Obsidian 的笔记软件，配合一个叫 Claude Code 的 AI 工具，来帮我持续整理知识。

简单说就是：我把看到的东西扔进去，AI 不只是帮我存档，它会**读、理解、整合**——把新内容和我已有的知识连起来，更新已有的笔记，标注矛盾的地方。知识只编译一次，但一直在复利。

这个思路来自 Andrej Karpathy（OpenAI 的创始成员之一）的一篇文章，他把它比作"让 AI 帮你维护一本不断生长的百科全书"。

**为什么这颗钉子真的是钉子：**
因为这件事有明确的痛点（信息散、不积累），AI 做的工作有清晰边界（整理、关联），判断和取舍还是我来做。不是为了用 AI 而用 AI。

---

### 案例二：我的个人网站（10分钟）

**问题是什么：**
我想有一个能展示自己作品的地方，但我不会写代码，或者说不想花时间学完整的开发流程。

**我用 Claude Code 来写网站。**

效果：
- 我告诉它我想要什么，它帮我写出来
- 遇到我看不懂的问题，我描述给它，它告诉我怎么改
- 我的角色是产品经理，它的角色是工程师

**这里有个关键：** 我需要能看懂结果对不对，需要知道自己想要什么。如果你连想要什么都说不清楚，AI 做出来的东西也是一团糟。这就回到了开头——锤子有用，但你得知道钉在哪。

---

### 收尾：我的判断标准（5分钟）

我现在用不用 AI，问自己三个问题：

1. **这件事有没有明确的"好"的标准？** 能定义好坏，AI 才能帮到你
2. **这件事是在积累还是在消耗？** 用 AI 图省事可以，但别让它替你思考
3. **这件事的判断权在不在我手上？** AI 是工具，不是决策者

## V2

> 更新：没有PPT，演示靠当场展示 Claude Code + Obsidian；加入 Obsidian Web Clipper；加入个人网站（半成品）；向金融听众推荐 Perplexity

### 核心主线

**"不要拿着锤子找钉子"** — 不是介绍 AI 有多厉害，而是分享我自己找到了哪几颗真正的钉子，以及怎么找到的。

---

### 分享顺序与内容

**一、开场（3分钟）**

不用暖场废话，直接抛问题：你现在用 AI 吗？用在哪？

然后说：大多数人用 AI 的方式，是拿着锤子到处找钉子——感觉没用就落后了，于是强行套用。今天我想分享的，是我自己真正找到的几颗钉子，以及一个给金融行业的工具推荐。

---

**二、钉子一：知识库（15分钟）**

*先说痛点，再演示*

痛点：信息很多，留不住。看了就忘，感觉在原地踏步。

我的解法：**Obsidian + Obsidian Web Clipper + Claude Code**

演示顺序：
1. 打开浏览器，展示 **Obsidian Web Clipper** — 看到一篇好文章，一键剪藏进 Obsidian，自动带上标题、链接、日期。这是"喂进去"的入口
2. 打开 Obsidian，展示 raw/ 和 wiki/ 的结构 — raw 是原材料，wiki 是 AI 编译后的知识页
3. 打开 **Claude Code**，当场演示：把一篇新素材丢进去，让 AI 读、提炼、写入 wiki，和已有内容建立关联
4. 展示一个已经成型的 wiki 页面（比如[[认知放松]]或[[卢德主义]]），说明这是读书+文章积累下来的，不是一次性生成的

说明这个思路来自 Andrej Karpathy，核心是：**知识只编译一次，但一直在复利**。

---

**三、钉子二：个人网站（10分钟）**

*半成品也可以展示，真实感比完美更重要*

痛点：想有一个对外展示自己的地方，但不会写代码。

我的解法：用 Claude Code 来写网站。我的角色是产品经理，它的角色是工程师。

演示：打开网站，展示现有的页面，坦诚说"这还是半成品，但它是真实存在的"。重点不是网站有多好看，而是**一个不会写代码的人，用 AI 做到了这件事**。

关键点：你得知道自己想要什么，AI 才能帮你做出来。说不清楚"好"是什么，结果就是一团糟。

---

**四、给金融从业者的工具推荐：Perplexity（5分钟）**

不需要演示太多，说清楚它解决什么问题就够了。

Perplexity 是 AI + 搜索的结合——它的每一个回答都附带原始资讯链接，不会凭空生成，可以溯源。对需要快速了解行业动态、政策变化、公司信息的金融从业者，比直接问 ChatGPT 更可信，因为你能看到它从哪里来的。

用法：把它当一个"有判断力的搜索引擎"，不是用来做决策，而是用来快速建立背景认知。

---

**五、收尾（3分钟）**

回到开头的问题：你找到你的钉子了吗？

我的判断标准很简单：
1. 这件事有没有明确的痛点？
2. AI 做完之后，判断权还在不在我手上？

AI 是工具，不是方向。方向还是得自己找。
