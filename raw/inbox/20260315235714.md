   📝 内容创作.md     链接公众号文章、选题、素材

  建立 PARA 或 CODE 工作流程：

  inbox/ 里的文件 → 定期整理 →

    - 是文章 → content/
    - 是投资记录 → investment/
    - 是待办 → 移到任务管理
    - 没用 → 删除或 .trash

  你现在只有 3 个视图，可以新增：

  # 投资记录.base
