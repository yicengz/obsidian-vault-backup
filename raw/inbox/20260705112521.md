> 与 Claude 的对话记录，2026 国庆格鲁吉亚 11 晚行程规划的建议与待确认项。

## 已定的事实

- 09-23 (三) 上海直飞第比利斯当天到
- 10-04 (日) 第比利斯中转飞回上海当天到
- 11 晚在地（大约 10.5 个可用整天）
- 机票已订，酒店和行程未定

## 硬约束

- 小龚肠胃弱、体力弱 —— 不徒步硬核山、每天强度留缓冲、少换酒店
- 期望节奏慢、重人文/自然感受、拒绝打卡
- 可自驾

## 已排除项（附理由）

- **斯瓦涅季 / 乌树故里**：路况差、颠簸大、高海拔、往返吃 2-3 天。对小龚不友好
- **瓦尔齐亚洞窟城**：单程 4h+，往返 8h+，探洞需体力。用 Mtskheta 附近的**乌普利斯齐赫**（近、同类岩凿古城）替代
- **巴统**：性价比低。定位赌城+海滨，人文密度不高，跟"文明十字路口"主题不对；6h 车 / 1h 飞任选一种都是一天折腾成本
- **亚美尼亚**：想加但代价大，需砍卡兹别克才能塞下（详见下方分析）

## 提议的行程骨架（Plan A：格鲁吉亚单国 + 酒乡加重）

11 晚 × 3 个据点，只换 3 次酒店：

| 日期           | 落脚               | 主要内容                                                              |
| ------------ | ---------------- | ----------------------------------------------------------------- |
| 09-23 (三)    | 第比利斯             | 直飞落地，酒店休息，晚上老城随便走走吃一顿                                             |
| 09-24 (四)    | 第比利斯             | 老城 + 硫磺浴（Abanotubani）                                             |
| 09-25 (五) 中秋 | 第比利斯             | Mtskheta 半日（兹瓦里修道院 + Svetitskhoveli），中秋晚上找有院子的餐厅                  |
| 09-26 (六)    | 第比利斯             | 缓冲/博物馆（国家博物馆 苏联占领厅）/ Dry Bridge 跳蚤市场                              |
| 09-27 (日)    | Sighnaghi        | 开车东去卡赫季（2.5h），下午城墙散步、俯瞰 Alazani 谷                                 |
| 09-28 (一)    | Sighnaghi/Telavi | Bodbe 修道院 + 家庭酒庄 qvevri 品酒（Pheasant's Tears、Twins Wine Cellar 之类） |
| 09-29 (二)    | Kazbegi          | 走军事大道北上（3.5h），沿途 Ananuri 城堡、Gudauri 观景、俄格纪念碑                      |
| 09-30 (三)    | Kazbegi          | 格尔盖蒂三一教堂 + 冰川谷慢慢逛（不硬爬）                                            |
| 10-01 (四)    | 第比利斯             | 返程（3.5h），路过 Jvari 补拍/乌普利斯齐赫（可选）                                   |
| 10-02 (五)    | 第比利斯             | 空日，按当时兴趣挑一个                                                       |
| 10-03 (六)    | 第比利斯             | 采购手信、餐厅回访                                                         |
| 10-04 (日)    | ✈                | 出发                                                                |

**为什么这么排：**

- 第比利斯前后各住一段，符合屯门/香港那种"再来一次"的复访感
- 中间 2 个据点各 2 晚，避免天天拖箱子
- 军事大道那段自驾体验本身是行程的一部分，但陈曦提到"超车彪悍"——建议**这段包车**而不是自驾，副驾更能放松看风景
- 卡赫季选 Sighnaghi 而不是 Telavi 做主据点：更小、更慢、山坡俯瞰，跟"松弛"锚点更贴

## Plan B：加亚美尼亚（要砍卡兹别克）

如果确实想去亚美尼亚，交换一下：

| 段落 | 晚数 | 备注 |
|---|---|---|
| 第比利斯 | 3 晚 | 老城 + 硫磺浴 + Mtskheta 半日 |
| Sighnaghi/Telavi | 2 晚 | 酒乡保留 |
| 埃里温 | 3 晚 | 陆路 Sadakhlo–Bagratashen 过境（半天），埃里温 + Garni 神庙 + Geghard 修道院 |
| 第比利斯收尾 | 3 晚 | 缓冲 + 手信 |
| **合计** | **11 晚** | |

**代价：** 卡兹别克整段（高加索雪山 + 格尔盖蒂三一教堂）砍掉。这是格鲁吉亚最标志性的画面之一。

**建议：** 除非亚美尼亚对你有特殊吸引力（比如宗教史、语言、种族灭绝纪念馆等主题很戳你），否则**优先 Plan A**。亚美尼亚以后单独规划一次 6-8 天更从容。
